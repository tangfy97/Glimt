# Security

Glimt reads and changes files on your Mac, so problems that could lose, expose or corrupt files are taken seriously.

If you find a security issue, please email **hello@tang-spark.no** instead of opening a public issue. Include the steps to reproduce it and the version of Glimt and macOS. You will get a reply within a few days, and a fix will be released as soon as it is ready.

Glimt makes no network connections, so most reports will be about file handling: moving, renaming, rotating or trashing the wrong file, following links unexpectedly, or reading outside the folder the user opened.
