# Glimt 方案

## 一、性能红线（验收标准）

| 指标 | 目标 | M1 状态 |
|---|---|---|
| 双指缩放 / 平移 | 跟手，ProMotion 120fps，0 掉帧（Instruments Hitches 验收） | 架构到位（系统 NSScrollView 缩放 + IOSurface 纹理）；**待 Hitches 实测** |
| 翻页 | 按键到出图 < 16ms | ✅ p95 3.7 ms（到 CA 提交） |
| 冷启动 | < 300ms | ✅ 270–295 ms 到窗口（M1 时 ~200 ms，工具栏和网格加了约 80 ms） |
| 一万张图的文件夹 | 网格 1 秒内出现，滚动不掉帧 | 列出 ~205 ms，首屏缩略图有缓存 3 ms ✅；滚动掉帧待 Hitches 实测 |
| 体积 | < 5MB，无第三方库 | ✅ 1.6 MB（含图标） |
| 内存 | 空闲 < 80MB，缓存有上限，内存紧张时释放 | ✅ 空闲 19 MB，缓存 ≤ 512 MB，监听内存压力 |

## 二、丝滑缩放

1. **看图用 AppKit `NSScrollView` + `allowsMagnification`**，不用 SwiftUI `MagnifyGesture`。✅
2. **缩放中主线程不解码、不读文件、不重绘。** 后台解码进 IOSurface，图层 `layerContentsRedrawPolicy = .never`。✅
3. **两级清晰度无缝切换。** 实际为三级：内嵌缩略图 → 屏幕尺寸 → 原图。捏合开始即解码原图，松手后换纹理；替换前一直显示低清版。✅
   超大图瓦片：⏳ 目前超过 6400 万像素会降采样。
4. **预加载**：前后各 2–3 张，按方向偏置；快速翻页时作废已划过的任务。✅
5. **网格捏合**：M2。
6. **网格 ↔ 看图转场**：M2。

## 三、守住"轻"

- 只用系统框架（AppKit、ImageIO、Core Animation、IOSurface）。✅
- IO 不上主线程。✅
- 缓存按字节计费、有上限。✅ 磁盘缩略图缓存：M2。
- 不做：账号、云同步、数据库、启动页、引导、动画特效。
- 关键路径 `os_signpost`（`Decode`、`Page Turn`），`scripts/bench.sh` 自动跑分。✅

## 四、里程碑

1. **M1：看图和缩放** ✅
2. **M2：网格** ✅ 缩略图网格（256/512 两档 + 磁盘缓存）、网格捏合缩放（O(1) 布局，跟手重排）、网格 ↔ 看图飞入飞回转场。
3. **M3：分拣** ✅ 数字键目标文件夹（⇧ 复制、⌥ 设置）、分拣栏（点击 / 拖放）、移到废纸篓、多级撤销重做。
4. **M4：补齐 Phoenix 其余功能** ✅ 无损旋转、重命名、幻灯片、信息面板、设置。⏳ 快捷键只能查看，不能自定义。
5. **M5：超越** ✅ 视频内联播放、动图、Finder 标签（显示 / 切换 / 筛选）、按类型和名称筛选、多种排序、文件夹自动刷新。
