# 对照评审：Phoenix Slides、同类产品与设计

日期：2026-10-21。表中标为"补上""采用""改为"的条目都已实现，并有自检覆盖文件操作部分。依据：Phoenix Slides 源码（帮助文档、菜单、偏好设置、幻灯片按键处理），Photo Mechanic、FastRawViewer、Just Look!、Pict-o-view 的公开介绍，以及两篇"去 AI 味"设计文章。

## 一、和 Phoenix Slides 的差距

| Phoenix Slides | Glimt 之前 | 处理 |
|---|---|---|
| 幻灯片按选择决定范围：没选 = 全部从头；选一张 = 全部从这张开始；选多张 = 只放选中的 | 只从选中那张开始 | **补上** |
| 随机播放、循环 | 只有循环 | **补上随机** |
| 在窗口里放幻灯片（按住 ⌥） | 一律全屏 | **补上** |
| Page Up / Page Down 跳 10 张 | 跳 1 张 | **改为跳 10 张** |
| `i` 在图上显示文件名和信息，再按一次加 EXIF | 只有独立的信息面板 | **补上信息叠层** |
| `h` / `?` 显示快捷键速查 | 只在设置里 | **补上速查叠层** |
| ⌘E 放大小图，⇧⌘E 大图按实际大小显示 | 只有设置项 | **补上菜单开关** |
| 旋转 180°、水平 / 垂直翻转 | 只有左右旋转 | **补上（同样无损）** |
| 设为桌面图片 | 无 | **补上** |
| 打开方式（子菜单） | 只有"用默认 app 打开" | **补上** |
| 移动到…… / 拷贝到……（任意文件夹，并记住） | 只有 9 个固定目标 | **补上"其他文件夹……"** |
| 全不选 ⇧⌘A | 无 | **补上** |
| 包含子文件夹 | 无 | **补上** |
| 缩略图 40 到 512 px | 72 到 360 pt | **扩到 56 到 480 pt，加 1024 px 档** |
| 按类型、添加日期排序 | 无 | **补上**（按 EXIF 拍摄时间排序需要读每个文件，暂不做） |
| 外观：跟随系统 / 浅色 / 深色 | 只能跟随系统 | **补上** |
| 新窗口 ⌘N、新标签页 ⌘T | 单窗口 | **补上** |
| 前往：宗卷列表、输入路径跳转 | 只有上一级 | **补上：常用位置、宗卷、前往文件夹 ⇧⌘G** |
| 状态栏显示选中项信息 | 只显示数量 | **补上大小合计** |
| 分组（F2–F12，跨启动保存） | Finder 标签 | 已覆盖：标签同样跨启动，还能在 Finder 里用 |
| 幻灯片里数字键改自动播放秒数 | 数字键用于分拣 | 不改：数字键在 Glimt 里统一是分拣，间隔用 `[` `]` 调 |
| JPEG 高级变换（渐进式、灰度、删标记） | 无 | 不做：太小众 |
| 删除 EXIF 缩略图 | 无 | 不做 |

## 二、比同类产品更好的地方（不增加复杂度和性能负担）

| 来源 | 做法 | 处理 |
|---|---|---|
| Photo Mechanic | RAW 文件先显示内嵌的 JPEG 预览，不等完整解码 | **采用**：屏幕尺寸那一级直接读内嵌预览；放大到原图才真正解 RAW |
| Photo Mechanic / FastRawViewer | RAW+JPEG 同名文件和 .xmp / .aae 旁车文件一起移动 | **采用**：分拣、废纸篓、重命名时一起处理（设置里可关） |
| FastRawViewer / Lightroom | 按住一个键临时看 100%，松开回去 | **采用**：按住 Z 在指针处看实际像素；轻点 Z 切换 |
| Photo Mechanic / Just Look! | 翻页时保持缩放比例和位置，用来对比连拍的对焦 | **采用**：显示 → 翻页时保持缩放 |
| Pict-o-view | 一键标记加"只看已标记" | 已有：Finder 标签加标签筛选 |
| 系统 | 共享菜单 | **采用**：工具栏和右键菜单 |
| 无障碍 | 系统"减少动态效果" | **采用**：开启时转场改为淡入淡出 |
| Just Look! | 连拍并排对比 | 暂不做：会明显增加界面复杂度 |
| FastRawViewer | 焦点峰值、直方图 | 暂不做 |

## 三、设计：去掉"AI 味"

对照两篇文章列出的特征，结合 macOS 平台惯例（系统字体、标准菜单和设置样式本身不是问题）。

| 问题（文章里的说法） | Glimt 里的位置 | 改法 |
|---|---|---|
| 所有东西都包进卡片 | 分拣栏 9 个圆角格子，没设置的也占一格 | 改成一行文字图例：只列已设置的目标（键位 + 名称），末尾一个"添加"，没有边框 |
| 圆角组件到处都是，圆角凭感觉 | 缩略图选中底板 7、分拣格 6、提示框 9 | 照片保持直角；选中框用同心圆角（外圆角 = 内圆角 + 间距）；只有浮动提示保留圆角 |
| 一切居中、图标加两行字的空状态 | 欢迎页和空文件夹 | 欢迎页左对齐，列出最近打开的文件夹，可以直接点；空状态去掉通用图标 |
| 冷暖灰混用 | 深色网格背景偏蓝灰，浅色是暖纸色 | 统一暖色温：深色用暖近黑，浅色用暖纸白 |
| 用符号代替文字 | 提示里的"→ 1 Keepers""⧉""● 红色" | 写成完整的话："已移到 Keepers""已拷贝到……""已加上红色标签" |
| 文案啰嗦、泛泛 | "Set folder…" 重复 9 次 | 只出现一次"添加分拣文件夹……" |
| 只有正常状态 | 读取中只是一个大图标 | 读取中、空文件夹、无匹配、文件打不开各有一句明确的话 |
| 动画不考虑减少动态效果 | 转场 | 跟随系统设置 |

## 四、语言

界面支持简体中文和英文，跟随系统语言。所有界面文字放进 String Catalog（`Localizable.xcstrings`），菜单、设置、提示、信息面板、快捷键表都翻译。Finder 标签名用系统给的本地化名称。
